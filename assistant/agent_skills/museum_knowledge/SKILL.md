# 博物馆知识和文物信息查询

**Skill Name:** museum_knowledge

**Skill Type:** global

**Description:** 提供博物馆知识和文物信息查询功能

## 功能介绍

本技能提供以下功能：
- 文物搜索和详细信息查询
- 展览信息获取
- 历史知识讲解
- 文物对比分析

## 允许使用的工具

- `search_artifact` - 搜索文物
- `get_artifact_detail` - 获取文物详细信息
- `get_exhibition_info` - 获取展览信息
- `explain_era` - 讲解历史时期
- `compare_artifacts` - 对比多个文物

## 使用示例

**用户:** 介绍一下唐三彩

**助手:** 唐三彩是中国唐代的一种低温铅釉陶器，以黄、绿、白三色为主，因此得名。它主要用于随葬的明器，造型丰富，包括人物、动物、生活用具等，充分反映了唐代的社会生活和艺术风格。

**用户:** 现在有什么特展？

**助手:** 目前有以下特展：
1. "千年瓷韵" - 中国陶瓷艺术展
2. "丝路遗珍" - 丝绸之路文物展
3. "盛世华章" - 唐代艺术精品展
