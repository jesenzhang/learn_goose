# Daily Report Skill

根据项目 git 提交历史生成格式化的工作日报。

## 功能说明

本技能通过分析 git 仓库的提交记录和代码差异，自动生成结构化的工作日报。

### 主要功能

1. **提交历史分析**：解析 git log 获取提交信息
2. **代码差异分析**：使用 git diff 获取变更统计
3. **格式化输出**：按功能模块分类展示工作内容
4. **多维度统计**：工作量、难度、作用等维度评估

## 可用工具

| 工具名称 | 描述 |
|---------|------|
| `analyze_commits` | 分析指定时间范围内的 git 提交记录 |
| `analyze_file_changes` | 分析指定文件的代码变更详情 |
| `generate_daily_report` | 生成格式化的工作日报 |
| `get_git_stats` | 获取 git 仓库统计信息 |

## 使用示例

### 示例 1：生成日报
```
请帮我生成昨天和今天的工作日报
```

### 示例 2：分析特定文件
```
分析 agent.py 最近有什么变更
```

### 示例 3：周报生成
```
生成这周（周一到今天）的工作周报
```

### 示例 4：特定作者
```
查看 jesenzhang 最近一周的提交记录
```

## 日报格式

生成的日报包含以下结构：

```
# 工作日报

## 日期（YYYY年MM月DD日）

### 功能名称
| 项目 | 详情 |
|------|------|
| **功能名称** | xxx |
| **工作内容** | - xxx<br>- xxx |
| **工作量** | xxx 行代码变更 |
| **难度** | ⭐x |
| **作用** | xxx |

## 总体统计
| 指标 | 数值 |
|------|------|
```

## 注意事项

1. 需要在 git 仓库目录下执行
2. 工作量按代码变更行数评估
3. 难度分为 5 级（⭐-⭐⭐⭐⭐⭐）
4. 功能名称需要根据提交信息推断或人工补充
